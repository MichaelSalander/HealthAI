# HealthAI 測試計畫

## 1. 測試帳號

```text
customer-a：客戶張小美
customer-b：客戶陳先生
consultant-a：健管師李曉雯
consultant-b：健管師王雅婷
admin：平台管理員
```

## 2. 客戶流程

- 登入後只能看到自己的健康資料。
- 建立健康檔案並保存。
- 上傳體檢報告，確認解析狀態。
- 手動新增健康指標，確認歷史趨勢更新。
- 未完成血液檢查時，發起服務會導向指定體檢中心。
- 完成檢查狀態後，可以重新建立諮詢需求。
- 建立諮詢請求後，可以看到待分配、已配對、房間中與已完成狀態。
- 進入諮詢房間後，客戶可以發送文字訊息、看到健管師回覆與未讀狀態。
- 點擊語音後可以看到 Mock 語音連線、結束與失敗狀態。

## 3. 健管師手機端流程

- 登入後進入健管師工作首頁。
- 收到新客戶配對通知。
- 查看被分配客戶的健康檔案、報告、指標與 AI Insight。
- 接受諮詢並進入房間。
- 在房間內回覆文字、發起語音並結束諮詢。
- 產生服務紀錄。
- 客戶在線等待時收到提醒。
- 設定離線後，不再收到新派單；時段與名額由 Admin 控制。

## 4. Admin 流程

- 查看待諮詢與在線等待儀表板。
- 手動派單、重新派單。
- 執行自動派單，確認只分配給符合條件的健管師。
- 修改服務方案或入口配置後，確認客戶端取得新資料。
- 查看通知、逾時與操作審計。

## 5. 權限測試

- customer-a 不可讀取 customer-b 的健康資料。
- consultant-a 不可讀取 consultant-b 未分配的客戶。
- consultant 不可修改平台價格與全局配置。
- 未登入呼叫受保護 API 必須回傳 401。
- 越權操作必須回傳 403。

## 6. 並發與可靠性測試

- 多個客戶同時建立諮詢請求時，派單不能超過公司配置容量。
- 同一請求與同一消息重試不能產生重複資料。
- WebSocket/Mock polling 斷線重連後可以補回未讀消息。
- 語音 Provider 失敗不能阻斷文字消息。
- AI、OCR、推播 Provider 失敗時，任務狀態可重試且不重複寫入。

## 7. 每次提交前

```text
pnpm run typecheck
pnpm run build:h5
console: pnpm run typecheck
console: pnpm run build
```

完成新功能時，必須同時更新測試案例與 `docs/TASKS.md`。
