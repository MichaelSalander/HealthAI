# Admin Web 開發規則

本目錄是公司 Admin 管理後台，不是健管師主要使用的手機端。

## Admin 職責

- 管理客戶、健管師、分類、等級與認證。
- 手動派單、自動派單與服務監控。
- 管理服務商品、價格、內容與指定體檢中心。
- 查看訂單、支付、佣金、結算與操作審計。

## 技術與資料

- 使用 Vue 3、TypeScript、Vite 與 Element Plus。
- 透過 API Layer 取得資料，不直接讀寫資料庫。
- 價格使用整數分，畫面展示時才轉換成元。
- 所有修改操作顯示成功或失敗結果。
- 高風險操作需要確認，並由後端產生審計紀錄。

## UI 規則

- 表格必須有 loading、empty、error 狀態。
- 派單、刪除、下架、改價等操作必須有確認提示。
- Admin 不直接修改客戶健康資料原始值。
- 健管師的手機工作流程不得複製成 Admin 表格；兩者職責不同。

## 驗收

- `pnpm run typecheck`
- `pnpm run build`
- 測試 Admin 角色權限、派單、內容配置與錯誤提示。
